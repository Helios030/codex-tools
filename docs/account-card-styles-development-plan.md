# 首页账号卡片四样式开发方案

## 1. 目标与边界

在现有账号首页中提供四种可持久化切换的卡片样式：

1. 星舰面板 `starship`
2. 液态玻璃 `glass`
3. 黑曜石 `obsidian`
4. 信号矩阵 `matrix`

四种样式共用相同的信息、交互和 DOM 结构，只通过根样式类改变视觉表现。设置切换后立即生效并保存，重新启动应用后保持选择。

本次只改账号首页卡片和对应设置，不改状态栏浮层、账号数据接口、额度刷新机制和账号切换后端。

## 2. 项目实际约束

- 主窗口宽度在 `src-tauri/tauri.conf.json` 中固定为 `420px`，`minWidth` 和 `maxWidth` 均为 `420px`。
- 首页 `.accountsPage` 左右各有 `18px` 内边距，卡片可用宽度约为 `384px`。
- 账号列表 `.accountRows` 已经是纵向 `flex` 列表并负责垂直滚动。
- 页面不能产生横向滚动；所有卡片必须 `width: 100%`、`min-width: 0`。
- 窗口最小高度为 `560px`，顶部工具栏固定可见，账号列表区域上下滚动。
- 卡片点击会打开账号详情；快捷切换按钮必须阻止事件冒泡，不能误触详情。
- 切换过程已有全局 `authBusy`、目标账号 `switchingId` 和 `handleSwitch`，继续复用。

## 3. 统一卡片结构

四种样式统一使用以下信息层级，不再维护条形和双弧形两套 JSX 分支：

```text
┌──────────────────────────────────────┐
│ 头像  邮箱 / 别名             PLUS  │
│       使用中 / 可切换                │
│                                      │
│ ┌──────────────┐  ┌──────────────┐   │
│ │ 本周剩余 61% │  │ 5小时剩余72% │   │
│ │ ━━━━━━━░░░░  │  │ ━━━━━━━━░░░ │   │
│ │ 09/21 重置   │  │ 今天18:49重置│   │
│ └──────────────┘  └──────────────┘   │
│ 更新于 14:32              快捷切换   │
└──────────────────────────────────────┘
```

### 固定尺寸建议

- 卡片宽度：`100%`，实际约 `384px`。
- 卡片内边距：`15–16px`。
- 两个额度块：`grid-template-columns: repeat(2, minmax(0, 1fr))`，间距 `8px`。
- 快捷切换按钮：宽约 `96px`，高度至少 `40px`；触控目标通过外围布局达到约 `44px`。
- 邮箱区域：`min-width: 0`、单行省略，完整内容保留在 `title` 和无障碍名称中。
- 重置时间：单行省略，不得撑宽卡片。

## 4. 四种样式定义

所有颜色优先使用项目现有主题变量，例如 `--card`、`--ink`、`--subtle`、`--line`、`--brand`、`--quota-week`、`--quota-five`、`--warning` 和 `--danger`。需要混色时使用现有 `color-mix()` 模式，不引入新主题系统。

### 4.1 星舰面板 `starship`

定位：默认样式，科技感最强，同时保持信息清晰。

- 深色层次面板、细亮边和右上角低强度径向光。
- 当前账号使用品牌色边框与轻微外发光。
- 两个额度块保留独立底色和水平进度条。
- 快捷切换按钮使用品牌色渐变；当前账号显示低对比度的“当前账号”。
- 浅色主题使用浅蓝灰面板，不强制切成纯黑卡片。

### 4.2 液态玻璃 `glass`

定位：柔和、精致，适合喜欢轻盈视觉的用户。

- 使用半透明表面、内高光和非常轻的背景色晕。
- 额度块采用轻微玻璃层次，不使用高模糊或大面积强光。
- 快捷切换按钮使用账号强调色到品牌紫色的短渐变。
- 当前账号以边框和阴影区分，不能只靠透明度。
- 在不支持 `backdrop-filter` 时仍以普通半透明背景正常显示。

### 4.3 黑曜石 `obsidian`

定位：克制、硬朗，适合低干扰和高对比度场景。

- 哑光深色表面，去除大面积渐变。
- 左侧短色条表示当前账号；非当前账号色条降低透明度。
- 额度块用左侧彩色竖线区分本周与 5 小时周期。
- 快捷切换按钮使用中性实体底色，悬停时出现强调色。
- 浅色主题仍保持深色卡片，但文字和边框必须满足可读性。

### 4.4 信号矩阵 `matrix`

定位：有图形语言、轮廓明确，接近工具面板风格。

- 页面账号区域使用极淡网格背景，不能影响文字阅读。
- 卡片使用硬朗圆角和小范围偏移阴影。
- 头像使用圆形纯色标识，额度块使用简洁描边。
- 快捷切换按钮使用实体强调色和小范围偏移阴影。
- 当前账号通过强调色边框与阴影共同标记。

## 5. 快捷切换交互

交互逻辑沿用 `AccountsGrid.tsx` 中的 `handleSwitch` 和现有 `onSwitch`：

| 状态 | 按钮文案 | 行为 |
| --- | --- | --- |
| 当前账号 | 当前账号 | 禁用，不重复切换 |
| 可用账号 | 快捷切换 | 调用现有 `handleSwitch` |
| 正在切换的目标账号 | 切换中… | 显示旋转图标并禁用 |
| 其他账号正在切换 | 快捷切换 | 全部禁用，避免并发切换 |
| 账号授权异常 | 重新登录 | 调用现有 `onReauthorize` |
| 切换失败 | 快捷切换 | 恢复可点击，错误继续走现有提示渠道 |
| 切换成功 | 当前账号 | 当前账号自动排到列表首位，卡片播放一次短高亮 |

按钮点击必须调用 `event.stopPropagation()`，避免同时打开详情。卡片其余区域继续支持鼠标点击、Enter 和 Space 打开详情。

四种样式不得改变按钮位置、文案和状态逻辑，防止用户切换皮肤后重新学习操作。

## 6. 设置页设计

复用现有“账号额度样式”设置行和 `onUpdateSettings`，将原来的两个选项改为四个选项。

- 四个选项在 `384px` 内容区使用 `2 × 2` 网格，避免四个按钮横向挤压。
- 使用现有 `radiogroup` 语义；方向键在四个选项间移动，Home 选择第一项，End 选择最后一项。
- 下方预览使用与首页相同的根样式类和结构比例，显示一张固定示例卡片。
- 预览中的“快捷切换”只展示状态，不执行真实切换。
- 点击选项立即调用 `onUpdateSettings`；保存中禁用四个选项。
- 设置说明改为“样式只影响账号卡片外观，额度数据与快捷切换行为保持一致”。

## 7. 设置模型与旧数据兼容

继续复用现有字段名 `accountQuotaDisplayMode`，避免增加字段和迁移脚本。字段值调整为：

```ts
type AccountQuotaDisplayMode =
  | "starship"
  | "glass"
  | "obsidian"
  | "matrix";
```

Rust 中的 `AccountQuotaDisplayMode` 同步为四个枚举值，默认值改为 `Starship`。

旧设置按以下规则读取：

| 旧值 | 新样式 |
| --- | --- |
| `dualArc` | `starship` |
| `bars` | `matrix` |
| 缺失或未知值 | `starship` |

实现时优先使用 Serde 的枚举别名和兜底能力完成读取兼容。保存设置后统一写入新值，不维护第二套迁移状态。

- `src/components/accounts/QuotaArc.tsx`
- `src/utils/quotaArc.ts`
- `tests/quotaArc.test.ts`

删除前再次使用 `rg` 确认引用为零。删除旧实现比同时维护六种模式更容易保证卡片宽度和交互一致。

## 9. 实施顺序

1. **设置模型**：先完成 Rust 枚举、TypeScript 类型、默认值和旧值兼容测试。
2. **统一卡片 DOM**：将 `AccountsGrid` 的 `bars` / `dualArc` 条件分支合并为一套固定宽度结构，先实现无主题的基础布局和完整切换状态。
3. **四种 CSS 皮肤**：在同一结构上依次实现 `starship`、`glass`、`obsidian`、`matrix`，不在 JSX 中复制样式分支。
4. **设置页**：接入四选一控件和样式预览，验证即时更新与持久化。
5. **删除旧代码**：清理双弧组件、工具函数、动画状态和旧样式。
6. **验证**：运行构建、测试和真实窗口视觉检查。

## 10. 验收标准

### 布局

- 主窗口保持固定 `420px` 宽，不修改 Tauri 窗口配置。
- 卡片在约 `384px` 内容区内无横向溢出。
- 账号列表只上下滚动，横向滚动条不会出现。
- 长邮箱、长别名、不同语言文案不会撑宽卡片。
- 在最小高度 `560px` 下，列表仍可滚动并操作所有账号。

### 样式

- 设置页可切换四种样式，首页立即更新。
- 重启应用后保持上次选择。
- 四种样式都支持深色和浅色主题。
- 当前、低额度、额度耗尽、未知额度和刷新失败均有清楚状态。
- 本周与 5 小时额度始终有文字标签，不能只依靠颜色区分。

### 交互

- 非当前账号始终能看到“快捷切换”按钮。
- 切换期间所有账号切换入口统一锁定，目标账号显示“切换中…”。
- 当前账号按钮显示“当前账号”并禁用。
- 授权异常账号显示“重新登录”，不会发起无效切换。
- 点击切换按钮不会打开详情；点击卡片其他区域仍能打开详情。
- 切换成功后当前账号排到顶部，失败后原当前账号保持不变。
- 键盘可以完成样式选择、打开详情和账号切换。

## 11. 验证命令与人工场景

完成实现后运行：

```bash
pnpm build
pnpm lint
node --test tests/manualMaintenance.test.ts
cargo test --manifest-path src-tauri/Cargo.toml account_quota_mode_persists_and_accepts_legacy_settings
```

人工检查场景：

1. 深色和浅色主题分别浏览四种样式。
2. 三个以上账号上下滚动，确认没有横向位移。
3. 使用超长邮箱和长别名检查省略与完整提示。
4. 快速连续点击不同账号，确认只发生一次切换。
5. 验证切换成功、切换失败、授权异常和额度刷新失败。
6. 验证 0%、低于 15%、100% 和未知额度。
7. 从旧设置 `bars` 和 `dualArc` 启动，确认分别映射到信号矩阵和星舰面板。

## 12. 本期不做

- 不允许用户自定义每个账号的颜色、圆角或光效强度。
- 不增加横向卡片轮播、拖拽排序和瀑布流布局。
- 不为每种样式维护独立组件。
- 不新增图表库、动画库或 CSS 框架。
- 不修改状态栏卡片和 Windows 任务栏组件。

以上能力不影响本次“四种样式、固定宽度、纵向滚动、快捷切换”的核心目标，有明确需求后再扩展。
