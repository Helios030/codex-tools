# 分析 / API 反代固定窄面板 UI/UX 设计

> 状态：待实现  
> 目标窗口：宽度固定 `420px`；默认高度 `720px`，可纵向调整  
> 主题：默认深色  
> 范围：仅重新设计“分析”和“API 反代”页面，本文件不包含代码实现

## 1. 设计结论

两个页面不再把桌面端多列布局压缩成单列长页面，而是使用同一套紧凑结构：

1. 窗口宽度始终为 `420px`；默认高度 `720px`，高度可在 `560px` 以上自由调整。
2. 单列内容，页面永不横向滚动。
3. 首屏只显示状态、关键数据和当前任务。
4. 用页面内分区切换替代所有模块同时展开。
5. 列表项只显示摘要，复杂配置进入就地详情页。
6. 主操作直接显示，导出、清除、删除等低频操作进入“更多”菜单。
7. 仅维护一套固定宽度的紧凑布局，不再设计或测试中、大宽度面板模式。

本次不新增图表库、状态库或弹窗框架，复用现有数据、SVG 图表、按钮、开关和主题变量。

## 2. 当前问题

### 2.1 分析页

- 四张统计卡在窄屏被降为四行，首屏几乎看不到实际分析内容。
- 周预算同时显示说明、输入框和两个按钮，占用过多高度。
- 项目、热力图、会话、提示词全部纵向堆叠，查找目标成本高。
- 会话表格最小宽度为 `860px`，在 `420px` 窗口只能横向滚动。
- 热力图主要依赖鼠标悬停，触控和键盘无法稳定查看详情。
- 刷新、CSV、JSON 三个按钮在标题区并列，操作优先级不清晰。

### 2.2 API 反代页

- 当前内容区左右各 `24px`，实际可用宽度约 `372px`，多组按钮和状态标签反复换行。
- 本地服务、用量图、路由、密钥、远程部署、公网访问全部展开，页面过长。
- 用量图上方同时存在维度、五个时间范围、指标和导出控件，窄屏下形成多行工具栏。
- 图表最小高度 `320px`，在默认窗口中占据大半屏。
- 每个 API Key 默认展开模型、推理等级、服务等级和日志，单个条目即可超过一屏。
- SSH 服务器列表与工作台在窄屏只是上下堆叠，没有形成明确的“列表 → 详情”流程。
- 外层卡片、内层卡片、状态胶囊叠加过多，视觉层级比信息层级更重。

## 3. 共用布局规范

| 项目 | 规范 |
| --- | --- |
| 窗口尺寸 | 宽度固定 `420px`；默认高度 `720px`；最小高度 `560px` |
| 内容可用宽度 | `420 - 18 × 2 = 384px` |
| 页面左右边距 | `18px` |
| 模块间距 | `12px` |
| 模块内边距 | `12px`，复杂表单可用 `14px` |
| 控件高度 | 常规 `36px`，主要操作 `40px` |
| 圆角 | 外层 `12px`，输入框/按钮 `8–10px` |
| 文字 | 标题 `16px`，正文 `13px`，辅助信息 `11–12px` |
| 内容溢出 | 名称单行省略；URL/密钥单行省略；日志允许模块内滚动 |
| 动效 | `160–220ms`；遵守 `prefers-reduced-motion` |

### 3.1 固定宽度窗口行为

- 左右边缘不能改变宽度，窗口始终保持 `420px`。
- 上下边缘可以调整高度；拖动四角时也只改变高度，不改变宽度。
- 最小高度为 `560px`，不设置业务层最大高度。
- 禁用最大化和全屏入口，避免系统操作改变窗口宽度；macOS 绿色窗口按钮不可用。
- 顶部拖动区负责移动窗口，不触发双击放大。
- 保留最小化与关闭能力。
- 内容高度超过可视区域时使用页面纵向滚动；增加窗口高度后自然显示更多内容。
- 所有页面都以 `420px` 为唯一宽度验收视口，不再使用响应式宽度断点。

视觉规则：

- 页面背景保持现有深色主题，不增加大面积渐变和玻璃模糊。
- 一个功能区只保留一层容器；内部用分隔线、留白和浅色底区分，不再套卡片。
- 品牌蓝只用于选中、运行中和主要操作。
- 成功、警告、错误必须同时使用图标或文字，不能只靠颜色。
- 页面级横向滚动禁止；代码和日志是唯一允许局部横向滚动的内容。

## 4. 分析页设计

分析页固定保留三层：

1. 紧凑页头：标题、刷新、更多。
2. 数据摘要：四项关键指标和周预算。
3. 内容切换：项目、会话、提示、活跃；同一时间只展示一个模块。

### 4.3 页头

- 删除 kicker 和长说明，只保留“分析”。

- “更多”菜单包含：
  - 导出 CSV
  - 导出 JSON
  - 数据来源详情
- 扫描时在页头下方显示一条细进度行，不再单独占用大卡片。
- 错误显示在页头下方的紧凑警告条，保留完整错误文本的展开入口。

### 4.4 数据摘要

- 四项数据放在一个 `2 × 2` 摘要容器中，用分隔线代替四张卡片。
- 指标固定为：总成本、近 7 日成本、Token、会话数。
- 价格来源不在每项中重复显示，统一放入“数据来源详情”。
- 最后一行显示更新时间；失败来源或异常用量存在时显示警告入口。
- 加载时保持相同尺寸，以短骨架或 `--` 占位，避免布局跳动。

- 编辑态仅显示金额输入、保存、取消；“清除预算”放入编辑态的更多菜单。
- 保存后立即回到摘要态，失败时保留输入值并在输入框下显示错误。
- 未设置预算时显示“设置周预算”，不绘制无意义的空进度条。

四个等宽分区按钮固定为“项目 / 会话 / 提示 / 活跃”。首次进入默认“项目”。切换后保留搜索词、滚动位置和当前选择；刷新数据不重置当前分区。

- 路径单行省略，鼠标悬停或键盘聚焦可查看完整路径。

#### 提示

- 保留现有排名、成本、预览、项目、模型、Token 和字符数。

#### 活跃

- 保留现有 `7 × 24` 热力图，不更换数据含义。
- `384px` 内容区内采用 `34px + 24 × 7px + 间距`，完整显示，不横向滚动。
- 小时仅标记 `00 / 06 / 12 / 18`，减少文字拥挤。
- 单元格支持点击、键盘聚焦和悬停，均显示星期、小时与 Token。
- 下方显示最小/最大色阶说明；移动指针离开后关闭提示。

### 4.7 数据来源详情

数据来源、扫描文件数、失败来源数、未解析分叉、用量异常和定价来源收进一个就地详情区，从“更多 → 数据来源详情”进入。它是诊断信息，不常驻页面底部。

## 5. API 反代页设计

### 5.1 信息结构

反代页拆成两层：

1. 始终位于顶部的服务控制器：运行状态、启动/停止、本地地址复制。
2. 四个互斥分区：状态、用量、密钥、远程。

路由策略、模型和 Codex 接管属于“状态”；SSH 部署和 Cloudflare 公网访问统一归入“远程”。

### 5.2 默认界面线框

```text
┌────────────────────────────────────┐
│ API 反代                            │
├────────────────────────────────────┤
│ ● 运行中 · 端口 8787          停止 │
│ http://127.0.0.1:8787          复制 │
│ 局域网地址                         ›│
├────────────────────────────────────┤
│   状态   │   用量   │   密钥   │  远程 │
├────────────────────────────────────┤
│ 本地服务                            │
│ 账号数              2               │
│ 当前账号            iam...@gmail.com │
│ 默认启动                         ●  │
├────────────────────────────────────┤
│ Codex 接管          未接管        接管 │
├────────────────────────────────────┤
│ 路由策略            平均分配        ›│
│ 可用模型            8 / 10          ›│
│ 服务密钥            ••••••••     复制 │
└────────────────────────────────────┘
```

### 5.3 服务控制器

- 第一行显示运行状态、实际端口和唯一主操作“启动/停止”。
- 第二行显示本地 Base URL，文本省略但复制按钮始终可见。
- LAN Base URL 默认折叠为“局域网地址”，展开后显示并可复制。
- 刷新状态放入页头“更多”菜单；启动/停止过程中用原位 loading 状态。
- 无账号、端口非法等情况禁用启动，并在按钮下方直接解释原因。
- 停止服务不弹窗；正在处理请求时如存在数据风险，再增加确认。

### 5.4 状态分区

按以下顺序展示紧凑设置行：

1. 本地服务：账号数、当前账号、默认启动、端口。
2. Codex 接管：当前 Base URL、接管/恢复操作。
3. 路由策略：平均分配或顺序切换。
4. 顺序阈值：仅在顺序切换时出现，显示滑杆和百分比。
5. 可用模型：显示启用数，点击进入模型选择子页。
6. 服务密钥：默认掩码，提供复制和重新生成。
7. 最近错误：无错误时不显示；有错误时显示摘要和“查看详情”。

端口仅在服务停止时可编辑。设置行点击后进入当前页面内的子页，顶部显示“‹ 返回”和标题，不叠加多层弹窗。

### 5.5 用量分区

```text
┌────────────────────────────────────┐
│ 按模型 ▾              调用量 ▾   ⋯ │
│  1h   24h   7d   14d   30d         │
├────────────────────────────────────┤
│                                    │
│       200px 高响应式折线图           │
│                                    │
├────────────────────────────────────┤
│ ● gpt-5.6-sol        120 次 / 830K │
│ ● gpt-6-astra         32 次 / 210K │
└────────────────────────────────────┘
```

- 第一行仅保留两个下拉：维度“按模型/按密钥”、指标“调用量/Token”。
- 第二行保留五个时间范围，使用等宽紧凑分段控件。
- 图表高度由 `320px` 调整为 `200px`；继续复用现有 SVG 和数据计算。
- 触控点击、指针移动和键盘左右键都能选择数据点；Tooltip 不依赖 hover。
- 图例改为单列行，每行显示系列名、总调用量和总 Token；名称省略。
- “更多”菜单包含导出 CSV 和清除统计。
- 导出时再显示 Key 过滤选择，不让导出控件常驻图表顶部。
- 清除统计必须二次确认，导出和清除的 loading 状态互斥。

### 5.6 密钥分区

列表页只显示摘要：

```text
API 密钥 3                         + 新增
────────────────────────────────────
生产环境                         ●  ›
1,280 次 · 4.2M Token · 10 分钟前
────────────────────────────────────
测试环境                         ○  ›
82 次 · 190K Token · 2 天前
```

- 开关可在列表直接操作；其余编辑进入密钥详情子页。
- 新增密钥进入单独子页，只要求名称和可选自定义密钥，避免双输入框挤在同一行。
- 详情页按顺序显示：名称、密钥、调用摘要、模型范围、推理等级、服务等级、最近日志。
- 密钥默认掩码；复制可直接执行；重新生成和删除位于“更多”菜单并二次确认。
- 模型、推理等级和服务等级使用可换行复选列表，但一次只展开一个配置组。
- 最近日志默认折叠，展开后每条日志改为三行摘要，不使用多列表格。
- 返回列表时保留滚动位置和正在编辑但尚未提交的输入值。

### 5.7 远程分区

远程分区顶部使用两个等宽子切换：“SSH 服务器 / 公网访问”。

#### SSH 服务器

- 首页只显示服务器列表和“新增服务器”。
- 每项显示名称、主机、运行状态、SSH 用户/端口、上次检查时间。
- 点击服务器进入详情子页，不在列表下方继续展开工作台。
- 详情页先显示当前状态和一个上下文主操作：部署、启动或停止。
- 安装状态、systemd、开机启动、PID 使用 `2 × 2` 摘要网格。
- Base URL、API Key、服务名合并为“连接信息”。
- SSH 配置默认折叠，点击“编辑配置”进入表单；表单保持单列。
- 日志和诊断默认折叠，代码区最大高度 `220px`，允许区内滚动。
- 部署进度继续使用现有进度提示，不再复制一份页面内进度组件。

#### 公网访问

- 顶部显示 cloudflared 的安装、运行和公开地址状态。
- 未安装时只显示说明和“安装”主按钮。
- 隧道模式使用两行单选项，不使用两张大卡片。
- 仅显示当前模式所需字段；高级网络选项默认折叠。
- 底部仅保留一个上下文主操作：启动或停止。
- Token、Account ID、Zone ID 等敏感字段默认掩码，并提供显隐按钮。

## 6. 交互与状态规则

### 6.1 导航状态

- 分析页和反代页分别记住最近分区，仅存本地 UI 状态，不改变 URL。
- 子页使用明确返回按钮；`Esc` 返回上一级，输入框聚焦时不拦截 `Esc` 清空行为。
- 从子页返回后恢复列表滚动位置和键盘焦点。

### 6.2 加载与刷新

- 首次加载用固定尺寸骨架或 `--`，不让模块高度跳动。
- 后台刷新保留旧数据，只在刷新按钮和更新时间上显示进度。
- 局部保存只锁定当前字段或当前条目，不锁死整个页面。
- 错误靠近触发操作显示，并保留可复制的完整错误详情。

### 6.3 危险操作

- 删除会话、删除/重新生成密钥、清除统计、移除远程服务器需要二次确认。
- 确认态直接替换原操作，不增加新弹窗；`3s` 后自动退出确认态。
- 停止本地或远程服务属于可恢复操作，默认不二次确认。

### 6.4 可访问性

- 所有图标按钮有中文 `aria-label` 和可见 Tooltip。
- 分区控件使用 tab 语义，支持左右方向键切换。
- 热力图和折线图必须提供键盘焦点与文本值，不能只依赖颜色或 hover。
- 焦点轮廓至少 `2px`，与深色背景保持明显对比。
- 状态变化通过 `aria-live="polite"` 播报，不抢占输入焦点。
- 文字放大到 `200%` 时仍无页面横向滚动。

## 8. 实施顺序

1. 先建立两个页面共用的紧凑页头、分区控件和就地子页行为。
2. 改造分析页摘要、预算和四个内容分区，彻底移除会话宽表格。
3. 改造反代页服务控制器与四个分区。
4. 改造密钥、SSH、公网访问的摘要列表和详情子页。
5. 完成键盘、触控、错误、空数据、长文本和不同窗口高度测试。

每一步都直接替换旧布局，不并存“旧版/新版”开关，避免维护两套 UI。

## 9. 验收标准

### 尺寸

- 应用启动宽度始终为 `420px`，默认高度为 `720px`。
- 左右边缘、四角、双击标题栏和系统最大化按钮都不能改变窗口宽度。
- 上下边缘和四角可以调整高度，但不能缩小到 `560px` 以下。
- 窗口可以通过顶部拖动区移动，移动不改变宽度或高度。
- `420 × 560`、`420 × 720` 和更高窗口均无页面级横向滚动。
- 顶部拖动区、全局导航和页面首个操作之间无覆盖。

### 分析页

- 首屏可同时看到四项摘要、预算和内容分区入口。
- 项目、会话、提示、活跃之间切换时不丢失搜索和滚动状态。
- 会话无需横向滚动即可阅读和删除。
- 热力图可通过鼠标、点击和键盘查看值。
- 刷新、导出、预算编辑、空数据和扫描错误均可完成。

### API 反代页

- 首屏可以确认运行状态、启动/停止并复制本地地址。
- 状态、用量、密钥、远程互不堆叠。
- 五个时间范围在一行完整显示，图表不裁切。
- 密钥列表一次至少能看到两个条目摘要；复杂权限只在详情中出现。
- SSH 服务器选择后进入独立详情，不与服务器列表上下挤压。
- cloudflared 安装、配置、启动和停止在 `420px` 固定宽度内可完成。
- 所有密钥、Token 和密码默认不以明文常驻显示。

### 回归

- 本地服务启动/停止、Codex 接管/恢复、端口保存、路由策略、模型开关不改变行为。
- 统计维度、时间范围、导出和清除不改变数据口径。
- API Key 创建、更新、重新生成、删除及权限绑定不改变行为。
- 远程部署、依赖安装、日志读取和 Cloudflare 隧道不改变行为。

## 10. 明确不做

- 不恢复小/中/大三套宽度布局；只允许用户调整窗口高度。
- 不新增总览仪表盘或新的统计指标。
- 不更换图表库，不引入新的 UI 依赖。
- 不把设置拆成新的全局页面。
- 不在本轮改变后端、配置格式或业务规则。
